# Security Policy

## Scope

Security reports may include vulnerabilities in SkillGuard itself, unsafe filesystem handling, secret leakage, protocol handling, CI workflows, or package/release integrity.

## Reporting

Use GitHub's **Report a vulnerability** feature if private vulnerability reporting is enabled. If it is not enabled yet, contact the maintainer privately through the contact method listed in the repository profile.

Do not open a public issue containing exploit details, credentials, or private user data.

## Response expectations

This is a community project and response times are not guaranteed. The maintainer will acknowledge reports when able, assess severity, coordinate a fix, and publish an advisory when appropriate.

## Supported versions

Until the first stable release, only the latest development version is supported.

## Important limitation

SkillGuard is a static analysis and testing aid. A clean report does not prove that a skill is safe, benign, or free of vulnerabilities.
